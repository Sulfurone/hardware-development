# TB6612 加热片驱动设计

这个方案用 TB6612FNG 的 A 通道驱动普通低压加热片。当前版本已经取消 NTC，不做闭环温控；程序只做低功率、短时间、周期性加热，用来验证加热片能工作并让红外温度看到变化。

## 适用范围

推荐搭配：

| 部件 | 建议规格 |
| --- | --- |
| 加热片 | `12V 10W` 普通加热片 |
| 电源 | `12V 2A` DC 电源 |
| 驱动 | TB6612FNG 模块，使用 A 通道 |
| 安全保护 | `KSD9700 60C 常闭温控开关` 串联加热片，强烈建议 |

不要用 `12V 15W` 或更高功率加热片直接接 TB6612。`12V 10W` 电流约 `0.83A`，更适合 TB6612 的 1A 级演示负载。

## 接线

| TB6612 模块 | 连接 |
| --- | --- |
| `VM` | 12V 电源正极 |
| `VCC` | XIAO `3V3` |
| `GND` | 12V 电源负极 + XIAO `GND` 共地 |
| `STBY` | XIAO `D7 / GPIO20` |
| `AIN1` | XIAO `D2 / GPIO4` |
| `AIN2` | XIAO `D3 / GPIO5` |
| `PWMA` | XIAO `D6 / GPIO21`，PWM 输出 |
| `AO1` | 加热片一端 |
| `AO2` | KSD9700 后再接加热片另一端 |

`KSD9700 60C 常闭温控开关` 串在加热片任意一根线上即可。推荐放在 `AO2 -> KSD9700 -> 加热片` 这一路。

必须共地：

```text
12V 电源负极 = 降压模块 GND = XIAO GND = TB6612 GND
```

## 控制方式

把 TB6612 的 A 通道固定为一个方向，PWM 控制加热功率：

| STBY | AIN1 | AIN2 | PWMA | 加热片状态 |
| --- | --- | --- | --- | --- |
| HIGH | HIGH | LOW | `0-255` | 加热，功率随 PWM 变化 |
| HIGH | LOW | LOW | 任意 | 关闭，高阻 |
| LOW | 任意 | 任意 | 任意 | 待机 |

加热片是纯电阻负载，没有方向概念。不要用 `AIN1=HIGH, AIN2=HIGH` 的短刹模式。

## 当前程序策略

主程序 `firmware/smart_coaster/smart_coaster.ino` 已经取消 NTC，默认策略是：

```text
每 15 秒加热 2.5 秒
PWM = 70 / 255
```

OLED 第三行会显示：

```text
Heat demo H70
```

或：

```text
Heat demo H0
```

参数在 `.ino` 文件顶部：

| 参数 | 默认值 |
| --- | --- |
| 加热 PWM | `70 / 255` |
| 单次加热时间 | `2500 ms` |
| 加热周期 | `15000 ms` |

如果加热太弱，可以先把 `kHeaterDemoPwm` 从 `70` 调到 `90`。如果加热太明显或 TB6612 发热，就调低或缩短 `kHeaterDemoOnMs`。

## 重要限制

- 取消 NTC 后，这不是闭环恒温，只是定时低功率加热演示。
- 不要长时间无人看管。
- 铝板明显变热后先断电观察。
- TB6612 是电机驱动芯片，不是专门的大功率加热 MOSFET，不适合长期大功率加热。
- 建议保留 `KSD9700 60C 常闭温控开关` 作为硬件断电保护。
- 不要用 220V 加热片。
