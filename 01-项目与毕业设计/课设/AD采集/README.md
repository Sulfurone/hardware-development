# STM32F103C8T6 + ADS1256 + CAN 交流参数采集

本工程使用 STM32F10x 标准外设库，从 ADS1256 单通道以 30 kSPS 连续采样，每 100 ms 计算交流 RMS 电压、低频和载频，通过 500 kbit/s CAN 上报。

## 接线

| STM32F103C8T6 | ADS1256 模块 | 说明 |
|---|---|---|
| PA4 | CS | SPI 片选 |
| PA5 | SCLK | SPI1 时钟 |
| PA6 | DOUT | SPI1 MISO |
| PA7 | DIN | SPI1 MOSI |
| PB0 | DRDY | 低电平表示数据就绪 |
| PB1 | RESET | 低电平复位 |
| GND | DGND | 数字地 |

CAN1 使用 PA11(CAN_RX) / PA12(CAN_TX)，必须外接 3.3 V CAN 收发器（如 SN65HVD230），不能将 PA11/PA12 直接 CANH/CANL。总线两端各接 120 ohm 终端电阻。

ADS1256 模块的 DVDD/逻辑电平必须与 STM32 的 3.3 V 兼容。被测交流信号必须先经过隔离、限流、分压和过压保护，并偏置到 ADS1256 允许的共模范围。严禁将市电直接 ADC 输入。

## CAN 协议

- 命令标准帧 ID: `0x201`；响应/数据 ID: `0x181`；默认节点号为 1。
- 所有 32 位整数为小端序。
- 命令帧前两字节为 `[command, sequence]`。

| 命令 | 数据 | 作用 |
|---|---|---|
| `01 seq` | 无 | Ping |
| `10 seq ch` | ch=0..7 | 选择 AINx-AINCOM 并开始 |
| `11 seq` | 无 | 停止采样 |
| `20 seq` | 无 | 立即重发最新结果 |
| `21 seq q0 q1 q2 q3` | Q16.16 | 设置前端电压换算倍率 |
| `22 seq u0 u1 u2 u3` | uV | 设置过零滞回阈值（ADC 输入折算） |

ACK 帧为 `[command|0x80, seq, channel, status, 0,0,0,0]`，status=0 表示成功，1 表示参数错误，2 表示未知命令。

每次结果由三帧组成：

| type | 字节 0..7 | value 单位 |
|---|---|---|
| `90` | `type,seq,ch,flags,value[4]` | RMS uV |
| `91` | 同上 | 低频 mHz |
| `92` | 同上 | 载频 mHz |

flags bit0=结果有效，bit1=ADC 接近满量程。例如 `50000 mHz = 50 Hz`。

## 电压标定

默认上报 ADS1256 输入端的 RMS 电压。若前端将被测电压缩小 100 倍，发送 `CMD_SET_SCALE_Q16` 的 Q16.16 数值 `100 * 65536 = 0x00640000`。精确应用标准交流源对整个前端进行系统标定。

## 重要限制

ADS1256 最高只有 30 kSPS，而且是 8 路复用的单个 ADC。本工程因此只对一个选中通道连续采样，载频建议低于 8~10 kHz。如果需要多通道同时相位、更高载频或谐波分析，应改用更高速的同步采样 ADC。

当前低频/载频分界约为 200~300 Hz，由 `measurement.c` 中的一阶滤波器决定。若实际频段不同，必须按实际的低频、载频范围重新设计滤波参数。
