# STM32F103 无源两线压电片驱动

本工程针对**两线无源压电陶瓷振动片**。STM32F103C8 的 TIM3 同时在 PA6 和 PA7 输出互补的 2 kHz 方波。两路信号经过 H 桥后，在压电片两端形成交替正负的交流电压，压电片上没有持续直流偏置。

| 项目 | 配置 |
| --- | --- |
| MCU | STM32F103C8 |
| H 桥 | TB6612FNG，使用 A 通道 |
| H 桥输入 1 | PA6 / TIM3_CH1 → AIN1 |
| H 桥输入 2 | PA7 / TIM3_CH2 → AIN2 |
| H 桥使能 | PA5 → PWMA，PA4 → STBY |
| 默认频率 | 2 kHz |
| PWM 波形 | 两路互补、各 50% 占空比 |
| 工程环境 | Keil + STM32 标准外设库 |

在 [User/main.c](User/main.c) 中修改 `PIEZO_FREQUENCY_HZ`，即可改变振动频率。建议从 500、1000、2000、3000、5000 Hz 逐步试验，选择振动最强的共振频率。

## 必需硬件：H 桥

无源两线压电片**不能直接接 MCU GPIO，也不能直接接 MCP4725**。本工程使用 TB6612FNG 的 A 通道；不要使用 L298N，它的压降太大，不适合 3.3–5 V 压电片。

| STM32F103 | TB6612FNG（A 通道） | 说明 |
| --- | --- | --- |
| 3.3V | VCC | H 桥逻辑电源 |
| 3.3V 或压电片额定电源 | VM | 电机/H 桥输出电源；首次建议 3.3 V |
| GND | GND | 必须共地 |
| PA6 | AIN1 | 定时器正相信号 |
| PA7 | AIN2 | 定时器反相信号 |
| PA5 | PWMA | A 通道使能，高电平有效 |
| PA4 | STBY | 取消待机，高电平有效 |
| 压电片线 1 | AO1 | H 桥输出 |
| 压电片线 2 | AO2 | H 桥输出 |

在 VM 与 GND 之间、靠近 H 桥放置 0.1 uF 陶瓷电容和 10 uF 以上电容。压电片上**不要并联续流二极管**，它是电容性负载，二极管会钳位交流驱动。

## MCP4725 的位置

MCP4725 不能作为本项目的功率驱动器：其输出是低电流模拟电压，直接接压电片只会在电压改变时产生极短暂的动作。在当前“能稳定振动”的最小方案中不需要它。

若后续增加可调强度功能，可让 MCP4725 控制专用压电驱动器的幅度控制端或可调电源模块；PWM 频率和 H 桥仍负责实际的交流驱动。

## 上电检查

1. 先不要接压电片，用示波器确认 PA6 和 PA7 均为约 2 kHz 方波且相位相反。
2. 确认 TB6612FNG 的 VCC、VM、GND、PWMA、STBY 已按表接好；程序上电后会自动将 PA4、PA5 拉高以启用芯片。
3. 接上压电片，再从 3.3 V VM 供电开始测试；确认正常后，才按压电片额定值提高 VM。
