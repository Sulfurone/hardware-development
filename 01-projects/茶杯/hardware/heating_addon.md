# 加热扩展方案

目标是在尽量不改变原智能杯垫方案的前提下，增加一个真实可工作的低温加热回路。原来的 `XIAO + OLED + MLX90614` 不改，继续用于红外测温和显示；新增加热部分独立工作。

## 推荐实现

使用成品 `XH-W1209 / W1209 12V 温控模块` 控制一片 `12V 10W` 薄膜加热片。温控模块自带 NTC 探头和继电器，设置成加热模式后，铝板低于目标温度就接通加热片，达到目标温度就断开。

这样做的好处是：

- 不改原 Arduino 固件。
- 不占用 XIAO 引脚。
- 原来的 OLED 和红外测温还能照常展示温度变化。
- 加热控制是独立闭环，能说成“恒温控制”。
- 只做 30 C 左右低温演示，不追求烫手加热，安全余量更大。

## 新增模块

| 模块 | 建议规格 | 作用 |
| --- | --- | --- |
| 温控模块 | XH-W1209 / W1209，12V，带 NTC 探头 | 设定目标温度并控制加热片 |
| 薄膜加热片 | 12V 10W，约 50x50 mm，背胶款 | 贴在铝板背面加热 |
| 电源适配器 | 12V 2A，DC 5.5x2.1 mm 常见接口 | 给温控模块和加热片供电 |
| 降压模块 | LM2596，12V 转 5V | 给原 XIAO 测温显示系统供电 |
| 过温保护 | KSD9700 60 C 常闭温控开关，或 72 C 温度保险丝 | 串在加热片供电线上，硬件断电保护 |
| 隔热材料 | 高温胶带、薄隔热棉 | 减少热量传到底壳和电路 |

## 接线

```text
12V 电源正极
  ├─ W1209 VCC
  └─ W1209 继电器输入端

W1209 继电器输出端
  └─ 过温保护
      └─ 加热片正极

12V 电源负极
  ├─ W1209 GND
  └─ 加热片负极

12V 电源
  └─ LM2596 降到 5V
      └─ 原 XIAO / OLED / MLX90614
```

W1209 的 NTC 探头贴在铝板背面，尽量靠近杯子中心区域，但不要挡住 MLX90614 的视场孔。加热片也贴在铝板背面，避开红外传感器开孔和固定结构。

## 安装位置

推荐从上到下这样叠：

```text
杯子
1.5 mm 铝板
薄膜加热片
高温胶带 / 薄隔热层
原 3D 打印主体
XIAO / OLED / MLX90614
底板
```

不要把加热片直接压到线材、XIAO、OLED 排线或 MLX90614 模块上。若空间不够，优先让加热片只覆盖杯子常接触的中心区域，不需要铺满整块铝板。

## 温控设置

建议演示初始设置：

| 参数 | 建议值 |
| --- | --- |
| 目标温度 | 30 C |
| 回差 | 1 C |
| 工作模式 | 加热模式 |
| 软件上限 | 不超过 40 C |
| 硬件保护 | 60 C 常闭温控开关或 72 C 温度保险丝 |

实际演示时，先空载通电 5-10 分钟，确认铝板温度缓慢上升且能在设定温度附近反复开关。再放杯子测试。不要把目标温度设太高，杯垫项目只需要能看到温度变化和闭环稳定，不需要把饮品真正加热到很烫。

## 展示说法

可以这样讲：

“原系统保留红外测温，用 MLX90614 观察杯底温度变化；新增的 NTC 探头贴在铝板背面，作为恒温控制反馈。加热片由独立温控模块闭环控制，目标温度设在 30 C 左右，主要用于低温保温和温度变化演示。”

这句话比较稳，因为它没有宣称红外能直接穿透杯子测液体温度，也没有把低功率杯垫说成烧水设备。

## 不建议第一版做的事

- 不建议把加热片直接接 XIAO。
- 不建议第一版改 Arduino 固件做加热控制。
- 不建议用 220V 加热片。
- 不建议加半导体制冷片；制冷需要散热片、风扇和防冷凝，结构会大改。
- 不建议目标温度超过 40 C；打印件、电池线、胶和传感器都不适合长期烤高温。
