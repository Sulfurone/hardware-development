# MAX30102 心率血氧扩展

这个扩展把 MAX30102 作为第三个 I2C 设备接到原有总线上。OLED、MLX90614 和 MAX30102 可以共用 `SDA/SCL`，因为它们常见地址分别是 `0x3C`、`0x5A` 和 `0x57`，互不冲突。

## 接线

| MAX30102 | XIAO ESP32-C3 |
| --- | --- |
| `VIN/VCC` | `3V3` |
| `GND` | `GND` |
| `SDA` | `D4 / GPIO6 / SDA` |
| `SCL` | `D5 / GPIO7 / SCL` |
| `INT` | 不接 |

建议先只接 OLED + MAX30102，上传 `firmware/oled_i2c_test/oled_i2c_test.ino`，串口应看到 `0x3C` 和 `0x57`。再把 MLX90614 接回去，正常会看到 `0x3C`、`0x57` 和 `0x5A`。

## 固件

主程序直接通过 I2C 寄存器初始化和读取 MAX30102，不依赖额外的 MAX30102 第三方库。这样可以避开 Arduino 本地库目录里多个 MAX3010x/MAX30101 库互相抢头文件的问题。

固件只启用红光和红外两个通道。心率和血氧是轻量估算，适合演示，不适合作为医疗数据。

屏幕显示逻辑：

```text
Cup 28.4C  Amb 27C
HR 72 bpm  O2 98%
WARM / Measuring... / Place finger
```

第一次把手指放上去时要等 8-15 秒，固件需要先收集一段红光和红外数据后才会计算心率和血氧。主程序会在串口里输出 `IR` 和 `Amp`，`IR` 表示红外原始读数，`Amp` 表示近一段 PPG 波形幅度；如果 `Amp` 长期很小，心率会不准。

## 注意

MAX30102 对手指压力、环境光、接触面积很敏感。手指太松、太用力、晃动或外壳漏光都会导致 `Measuring...` 或读数跳动。这个功能用于演示，不用于医疗判断。

读数更稳的做法：

- 用黑色泡棉或外壳遮住传感器周围漏光。
- 手指轻压并保持不动，不要用力按到发白。
- 先让读数稳定 10 秒左右再展示。
- 若 `Amp` 一直偏小，检查传感器窗口是否贴到手指、模块是否反装、红光/红外灯是否亮。
