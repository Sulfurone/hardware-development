# 本地整理规则

按用途移动顶层目录，避免更改工程内部相对路径。所有原文件保留在本地，未删除压缩包、安装包、视频和旧工程产物。

`tools/maintenance/organize.py` 包含目录映射和上传过滤规则。本地审计文件存放于 `.local-audit/`，该目录被 Git 忽略。

重新执行整理脚本会重新生成 `.gitignore` 和本地审计清单；运行前应先保存自己添加的忽略规则。脚本不会覆盖已存在的目标目录。文档筛查基于文件名及可提取文本，PDF 取前 15 页；图像形式的文字不能由该流程识别。

公开资料可能包含多套相近工程，保留这些工程有助于比较硬件版本和实现方式。压缩包副本和编译产物未纳入 Git。
